# 课堂笔记

每节课的讲解都落在这里，和代码一起进版本库。**聊天记录会丢，笔记不会。**

## 怎么用

- 上课时跟着对话走，课后回来看笔记巩固
- 卡住时先查对应笔记的「常见坑」
- 做题时不要看 `<details>` 里的答案，先自己写
- 你可以在任何一页末尾加「我的理解」，写错了也没关系，改一次记一辈子

## 每篇笔记的固定结构

以后每节课都按这个模板写，方便你形成预期：

```
0. 一句话      —— 这节课到底解决什么问题
1. 心智模型    —— 一张图，先说清全局再看细节
2. 逐个概念    —— 每个概念配一段代码 + 为什么
3. 代码走读    —— 对应 src/lessons/xx.js 的结构
4. 动手实验    —— 拆掉会怎样，改错会怎样
5. 自检        —— 带折叠答案
6. 常见坑      —— 报错原文 → 原因 → 修法
7. 延伸        —— 想深入看哪里
```

## 约定

- 代码块标注语言，保持可直接复制运行
- 答案一律放 `<details><summary>答案</summary>` 里
- 涉及 three.js 源码的位置，写成「仓库相对路径」，方便对着 r187 查
